Debug peta & aset kota
======================

Buka:
  ?mapdebug=1
  ?mapdebug=1&mapfocus=derawan&mapzoom=0.4

Layar debug (sederhana):
  1. Peta (klik peta = mapX/mapY)
  2. Tombol pilih kota (klik = zoom, tanpa main)
  3. Status aset BG / musik per kota
  4. Tombol "Selesai debug" → konfirmasi → kembali mode normal

Tidak tampil: pilihan latihan/petualangan, tempo, Back/Next.

File aset:
  public/cities/bg/{id}.webp|png|jpg
  public/cities/music/{id}.mp3

Lihat juga README.md bagian "Debug peta & aset kota".


=== MODE UJI MAIN (seperti pemain, semua terbuka) ===
URL (HP/PC/PWA — tempel di address bar):
  ?playdebug=1
  ?debug=1

Atau di Pengaturan → Masukkan kode progress:
  unlock all   /   buka semua   /   edmon halim the great
Kembali normal:
  lock all   /   normal   /   kunci semua

Perbedaan:
  ?mapdebug=1  → editor peta + audit aset (tidak main skor)
  ?playdebug=1 → main seperti biasa, SEMUA kota bisa dipilih (Indo…USA)
  Normal play  → hanya sampai ujung konten terbuka (saat ini Port Moresby / Oceania)
