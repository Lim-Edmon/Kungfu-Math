Debug peta & aset kota
======================

Buka:
  ?mapdebug=1
  ?mapdebug=1&mapfocus=derawan&mapzoom=0.4

Layar debug (sederhana):
  1. Peta (klik peta = mapX/mapY)
  2. Tombol pilih kota (klik = zoom, tanpa main)
  3. Status aset BG / musik per kota
  4. Tombol "Selesai debug" → konfirmasi → kembali mode normal

Tidak tampil: pilihan latihan/petualangan, tempo, Back/Next.

File aset:
  public/cities/bg/{id}.webp|png|jpg
  public/cities/music/{id}.mp3

Lihat juga README.md bagian "Debug peta & aset kota".
