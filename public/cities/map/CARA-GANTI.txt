Atur koordinat pin (dev)
========================
URL:
  ?mapdebug=1
  ?mapdebug=1&mapfocus=jakarta&mapzoom=0.4
  ?mapdebug=1&mapzoom=2

Klik peta → panel mapX / mapY (0–100, absolut di gambar penuh)
  mapX lebih besar = kanan (timur)
  mapY lebih besar = bawah (selatan)

Edit field mapX/mapY di src/lib/adventure.ts
Setelah ganti file peta, koordinat lama biasanya harus di-mapping ulang.
