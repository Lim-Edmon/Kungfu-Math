Atur koordinat pin (dev)
========================
URL:
  ?mapdebug=1              → semua kota, zoom longgar, hanya titik + nama (kecil)
  ?mapdebug=1&mapzoom=2    → lebih zoom OUT (angka besar = lebih jauh)
  ?mapdebug=1&mapzoom=0.6  → lebih zoom IN

Contoh:
  http://localhost:5173/?mapdebug=1
  http://localhost:5173/?mapdebug=1&mapzoom=1.5

Edit mapX / mapY di src/lib/adventure.ts
  mapX lebih besar = kanan (timur)
  mapY lebih besar = bawah (selatan)

Hapus query string jika sudah pas.
