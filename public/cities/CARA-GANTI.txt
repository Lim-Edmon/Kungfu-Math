Kota — ganti BG & musik tanpa ubah kode
=====================================

Folder:
  public/cities/bg/{id-kota}.webp   (disarankan)
  public/cities/bg/{id-kota}.png
  public/cities/bg/{id-kota}.jpg
  public/cities/music/{id-kota}.mp3

Contoh Jakarta:
  public/cities/bg/jakarta.webp
  public/cities/music/jakarta.mp3

Id kota MVP: jakarta, bandung, yogyakarta, surabaya, medan,
makassar, bali, malacca, penang, kuala-lumpur, singapore

BG (gambar):
  - Format kecil: WebP (paling hemat) atau JPG
  - Resolusi: lebar 720–1080 px cukup (HP + tablet)
  - Ukuran file target: < 120 KB (maks ~200 KB)
  - Jangan terlalu tajam/rame — opacity di game sudah dikurangi

Musik:
  - MP3, loop ~8–15 detik
  - Mono atau stereo, bitrate 64–96 kbps
  - Target: < 150 KB per file
  - Kalau file tidak ada → pakai BGM default / diam

Peta:
  - Pin diatur di src/lib/adventure.ts (mapX, mapY = persen 0–100)
  - Bukan di file gambar — ganti gambar peta nanti cukup sesuaikan mapX/mapY
