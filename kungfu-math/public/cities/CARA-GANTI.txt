Kota — BG & musik (ganti file saja)
===================================

NAMA FILE
- Harus HURUF KECIL = id kota (jakarta, bukan Jakarta)
- Di server Linux/Vercel: case-sensitive → Jakarta.webp TIDAK kepakai

BG (gambar)
- Format yang dibaca (urut coba): .webp → .png → .jpg
- Format lain (gif, avif, bmp) TIDAK otomatis
- Disarankan: WebP, lebar 720–1080px, < 120KB
- Contoh: public/cities/bg/jakarta.webp
- Tidak ada file kota → pakai public/cities/bg/default.webp

MUSIK
- Hanya .mp3: public/cities/music/jakarta.mp3
- Loop 8–15 detik, < 150KB
- Tidak ada file → pakai /sounds/bgm.mp3 (default)
- Belum ada bgm.mp3 juga → diam (tanpa error)

Id MVP: jakarta bandung yogyakarta surabaya medan makassar
         bali malacca penang kuala-lumpur singapore

PETA / PIN
- mapX mapY di src/lib/adventure.ts (persen 0–100 pada peta SVG jalur)
- Bukan lat-long dunia nyata; posisi relatif jalur MVP
- Nanti peta dunia: berikan basemap → koordinat bisa dibantu mapping
